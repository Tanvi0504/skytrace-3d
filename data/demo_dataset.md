# Demo dataset status

`data/test/example.mp4` is a small checked-in engineering test clip used by Steps 1, 8, and 9. Its original capture source and redistribution licence are not recorded in the repository. Therefore it is **not represented as a licensed SIH demo dataset** and must not be presented as one.

The deterministic UI backup is `outputs/processed-demo`. It is explicitly labelled **PRE-PROCESSED DEMO RESULT** and exists to exercise the interface when a live reconstruction cannot run.

Before judging, replace this gap with a real single-pass drone video that has documented provenance, permission/license, capture date, location constraints, and any allowed GPS metadata. Add only a small approved clip to the repository; keep large raw videos outside Git and document a stable download/checksum procedure.
